# ms-portfolio-site

Portfolio site for Marc Schroeder. Built with Vite, React, TypeScript and Tailwind CSS, with project content served from Sanity.io.

```sh
nvm use          # Node 22, from .nvmrc
npm install
npm run dev      # http://localhost:5173/portfolio-site/
npm run deploy   # build and publish to GitHub Pages
```

The previous Create React App version lives at the `legacy-v1` tag.
